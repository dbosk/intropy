Vi är intresserade av att utvärdera hur mycket ni lärt er från vår
undervisning. För att kunna mäta hur mycket ni har lärt er, måste vi
börja med att mäta hur mycket ni redan kan innan. Därför kommer ni att
få inleda med ett diagnostiskt prov.

Några av er har programmerat tidigare, men de flesta har inte det.
Förväntningen är därför att de allra flesta inte kommer kunna svara på
frågorna i provet. Om ni inte kan svara, känn inte att ni är dåliga på
något vis, det vore konstigt om ni kan svara på frågorna innan ni blivit
undervisade om innehållet.

Tryck på nästa för att komma till provet.
