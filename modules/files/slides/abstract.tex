\emph{Summary:}
Denna modul introducerar filhantering i Python.
Studenter lär sig skillnaden mellan flyktigt och oflyktigt minne,
hur man läser och skriver filer, samt hur man strukturerar data med filformat
som CSV.
Modulen kopplar filhantering till tidigare kunskap om \mintinline{python}{print()}
och \mintinline{python}{input()}.

\emph{Intended learning outcomes:}
Efter denna modul ska studenten kunna:
\begin{enumerate}
  \item \label{FilesLO1}%
    Förklara skillnaden mellan primärminne och sekundärminne samt varför filer
    behövs för persistens.
  \item \label{FilesLO2}%
    Använda filoperationer (\mintinline{python}{open()},
    \mintinline{python}{read()}, \mintinline{python}{write()},
    \mintinline{python}{close()}) korrekt.
  \item \label{FilesLO3}%
    Tillämpa kontexthanterare (\mintinline{python}{with}-satsen) för säker
    filhantering.
  \item \label{FilesLO4}%
    Skilja mellan text- och binärfiler samt välja lämpligt läge vid öppning.
  \item \label{FilesLO5}%
    Läsa och skriva strukturerad data med CSV-format med hjälp av
    \mintinline{python}{csv}-modulen.
\end{enumerate}

\emph{Prerequisites:}
Studenten bör känna till:
\begin{itemize}
  \item Variabler och datatyper (strängar, listor, dictionaries)
  \item Funktioner (\mintinline{python}{print()}, \mintinline{python}{input()})
  \item Grundläggande programstruktur (loopar, if-satser)
\end{itemize}
