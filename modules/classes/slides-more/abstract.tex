% Summary
\emph{Sammanfattning:}
Detta kapitel fördjupar kunskapen i objektorienterad programmering genom att 
visa hur man överlagrar operatorer i Python. Vi bygger en komplett klass för 
matematiska bråk (\mintinline{python}{Fraction}) som stödjer aritmetiska 
operationer. Genom detta praktiska exempel lär vi oss om dundermetoder för 
operatoröverlagring, egenskaper (\foreignlanguage{english}{properties}), 
typkonvertering och hur man designar en matematisk klass. Vi ser hur Python 
gör det möjligt att skapa egna typer som beter sig som inbyggda typer.

% Motivation and intended learning outcomes
\emph{Avsedda lärandemål:}
Efter att ha genomfört detta kapitel ska du kunna:
\begin{itemize}
  \item Implementera dundermetoder för aritmetiska operationer 
    (\mintinline{python}{__add__}, \mintinline{python}{__mul__}, etc.)
  \item Förstå skillnaden mellan \mintinline{python}{__add__} och 
    \mintinline{python}{__radd__} (och motsvarande för andra operatorer)
  \item Använda \mintinline{python}{@property}-dekoratorn för att skapa 
    egenskaper
  \item Implementera typkonvertering med \mintinline{python}{__str__}, 
    \mintinline{python}{__float__} och \mintinline{python}{__int__}
  \item Förstå när operatorer är kommutativa och hur det påverkar implementationen
  \item Designa en klass som representerar en matematisk entitet
  \item Använda \mintinline{python}{isinstance()} för typkontroll och polymorfism
\end{itemize}

% Prerequisites
\emph{Förkunskaper:}
För att förstå detta kapitel bör du vara bekväm med:
\begin{itemize}
  \item Grundläggande objektorienterad programmering (klasser, objekt, metoder)
  \item Dundermetoder (\mintinline{python}{__init__}, \mintinline{python}{__str__})
  \item Matematiska bråk och deras aritmetik
  \item Grundläggande Python-syntax
\end{itemize}
