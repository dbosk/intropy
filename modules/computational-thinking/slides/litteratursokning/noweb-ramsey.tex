\section{Research Context}
Research question: Is noweb the literate-programming tool whose chunk
notation the course uses, and is it described in Ramsey, ``Literate
programming simplified'', IEEE Software 11(5), 1994, pp.~97-105?

A paper is RELEVANT if it describes, uses, evaluates or criticises noweb
or a directly comparable language-independent literate-programming tool
(WEB, CWEB, nuweb, FunnelWeb), or if it bears on the chunk notation
itself or on the attribution of noweb to Norman Ramsey.

Assign exactly one of these four category tags:

\begin{itemize}
\item
  supports-claim: bears on the claim AND supports it. Ramsey's own
  description of noweb, papers that use noweb or its notation, and
  descriptions of comparable language-independent literate-programming
  tools that place noweb in that family.
\item
  qualifies-claim: bears on the claim BUT contradicts or narrows it.
  Criticism of literate programming as a practice, evidence that noweb
  or literate tools were not adopted, or claims that some other tool or
  author is the source of this notation.
\item
  adjacent-subtopic: computer science or software engineering work with
  NO bearing on noweb or its notation. Documentation tooling in general,
  program comprehension, notebook research, code generation, or
  literate-programming work that does not concern the tool or the
  notation.
\item
  off-topic-false-hit: not about literate programming or programming
  tools at all. Literacy and language-education research, unrelated uses
  of ``web'', ``simplified'', ``chunk'' or ``programming'' (linear
  programming, dynamic programming, TV programming), medicine, biology.
\end{itemize}
