at all.

RELEVANT (keep): the paper is about programming, computer science,
software, algorithms, CS/programming education, or computational
thinking -- even if it is only a specific tool, intervention, platform,
assessment instrument, or an adjacent subtopic within computing
(debugging, robotics, pair programming, notional machines, code

etc.).

appeared only on keyword overlap -- e.g.~medicine, biology, chemistry,
ecology, aerospace or mechanical engineering, economics, law, library or
archival science, quantum-computing hardware/physics, or pure
mathematics/logic with no connection to programming education.
